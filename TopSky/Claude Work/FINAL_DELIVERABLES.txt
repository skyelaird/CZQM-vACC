KEY LEARNINGS FOR FUTURE
-------------------------

LAYERS:
- Control drawing order (higher = on top)
- Valid range: -999 to -1, 1 to 999
- Layer 0 reserved for static elements
- Optional (defaults to 1)

FOLDERS:
- Organize maps in UI
- Required for every map
- No relation to layers
- Special names auto-hide from Maps Window

MAPS:
- Individual drawable elements
- Must specify folder
- Can optionally specify layer
- One map = one folder = one layer

INDEPENDENCE:
- Same folder can contain maps on different layers
- Same layer can contain maps from different folders
- Layers control WHAT draws on top
- Folders control WHERE in UI
